Abstract

This study investigates whether historical search performance and engagement signals can identify content with future refresh opportunities. Using the FlyRank ML Internship Warehouse, historical content-level search and engagement features were used to predict whether content would meet a predefined future-click opportunity threshold. A majority-class baseline was compared with a Random Forest classifier using a held-out validation split. The Random Forest achieved 0.9199 accuracy, 0.6890 F1, 0.9014 ROC-AUC, and 0.7659 PR-AUC. The resulting ranking achieved an observed Precision@20 of 1.00 on the validation set and is presented as decision-support evidence rather than a causal claim.

1. Question

Research question

Can historical search performance and engagement metrics be used to identify content that should be refreshed?

Decision supported

This project supports content managers in prioritizing pages for review by ranking content based on observed search performance trends and engagement metrics.

2. Data

Dataset: FlyRank ML Internship Warehouse.

Table: fact_content_daily_performance.

Analysis window: March 1–31, 2026. March 1–21 was used for historical features and March 22–31 for future outcomes.

Features included impressions, clicks, average position, pageviews, sessions, users, engaged sessions, total engagement time, and CTR.

Records without a content identifier were excluded. Engagement fields with no recorded value were treated as zero where appropriate, and missing average-position values were median-imputed.

No client names, URLs, search queries, credentials, or private identifiers are exposed. Content identifiers are hashed IDs.

3. Methodology

Historical observations were aggregated by content identifier to create past-period features. The future target used clicks from March 22–31. The opportunity threshold was the 90th percentile of future clicks; items at or above it received label 1.

A majority-class DummyClassifier was used as the baseline. A Random Forest classifier with 200 trees, balanced class weights, a fixed random seed, and parallel processing was trained.

An 80/20 stratified split was used for training and held-out validation. Baseline and Random Forest results were evaluated on the same validation set.

Leakage check: future-period outcomes were not used as model features. Future outcomes were used only for label creation and evaluation.

5. Limitations

  • This analysis is observational and based on one March 2026 analysis window.
  • The model does not establish causation or explain Google's ranking algorithm.
  • Validation performance is based on one held-out split and may differ on other periods or datasets.
  • Precision@20 is an observed result for this validation set, not a universal guarantee.
  • Recommendations are for decision support and human review, not automated publishing.
